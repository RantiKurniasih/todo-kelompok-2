# To-Do List Kelompok

## Deskripsi Aplikasi
To-Do List Kelompok merupakan aplikasi sederhana berbasis web yang digunakan untuk mencatat dan mengelola daftar tugas. Aplikasi ini dibuat menggunakan HTML, CSS, dan JavaScript sebagai bagian dari praktikum Rekayasa Perangkat Lunak (RPL) dengan menerapkan metode Scrum serta penggunaan Git dan GitHub untuk kolaborasi tim.

## Tujuan Pembuatan
Aplikasi ini dibuat untuk menerapkan konsep pengembangan perangkat lunak menggunakan metode Scrum serta melatih kerja sama tim dalam mengelola kode program menggunakan Git dan GitHub.

## Fitur Aplikasi
1. **Tambah Tugas**: Pengguna dapat menambahkan tugas baru melalui kolom input. Tugas tidak dapat ditambahkan jika kolom masih kosong.
2. **Tandai Tugas Selesai**: Pengguna dapat mengeklik tugas untuk menandainya sebagai selesai. Teks tugas akan dicoret dan berubah warna menjadi abu-abu.
3. **Hapus Tugas**: Pengguna dapat menghapus tugas dengan mengeklik dua kali pada tugas yang ingin dihapus.
4. **Hitung Jumlah Tugas**: Aplikasi menampilkan jumlah tugas yang tersedia dan memperbarui jumlahnya secara otomatis ketika tugas ditambahkan atau dihapus.
5. **Tampilan Sederhana dan Rapi**: Aplikasi memiliki tampilan yang sederhana sehingga mudah digunakan dan dipahami oleh pengguna.

## Teknologi yang Digunakan
- **HTML**: Membuat struktur halaman aplikasi.
- **CSS**: Mengatur tampilan dan desain aplikasi.
- **JavaScript**: Mengatur fungsi dan interaksi pada aplikasi.
- **Git**: Mengelola versi kode program.
- **GitHub**: Menyimpan repository dan mendukung kolaborasi antaranggota kelompok.

## Cara Menjalankan Aplikasi
1. Clone repository ke komputer:
   git clone https://github.com/RantiKurniasih/todo-kelompok--2.git
2. Masuk ke folder proyek:
   cd todo-kelompok--2
3. Buka file `index.html` menggunakan browser seperti Google Chrome.
4. Aplikasi To-Do List siap digunakan.

## Metode Pengerjaan
Pengembangan aplikasi dilakukan menggunakan metode **Scrum** dalam satu sprint. Setiap anggota memiliki tanggung jawab berdasarkan user story yang telah ditentukan.

Proses pengerjaan menggunakan Git dan GitHub dengan tahapan:
1. Membuat repository bersama.
2. Membuat branch sesuai tugas masing-masing anggota.
3. Melakukan coding dan commit perubahan.
4. Mengirim Pull Request untuk diperiksa oleh reviewer.
5. Melakukan review dan merge ke branch utama (`main`).
6. Melakukan pengujian aplikasi setelah seluruh fitur digabungkan.
